-Cleaned up a lot of inactive/dead code

-Made a fundamental change to the reward system, incorporating an idea inspired by COMA (Counterfactual Multi-Agent Policy Gradients)
 to fix a credit-assignment flaw in how task completion and collaboration were rewarded

-Previously, when a task was completed, the entire completion bonus went only to whichever agent happened to be 
the final (Nth) contributor — a timing artifact, not a measure of who actually mattered. Now the reward is split
 evenly across all contributors, since in a quota-based task each one is equally pivotal

-Previously, an agent that chose to "collab" and invite a peer got no reward back based on whether that invite 
actually helped. Now, if the invited peer goes on to contribute to the task, the inviter's original decision 
gets a small direct reward — giving the system a counterfactual signal it didn't have before
