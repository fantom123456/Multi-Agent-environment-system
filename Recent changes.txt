9/16/26
-Cleaned up unresolved Git merge conflict markers from previous branch pulls across orchestrator.py and project tracking files.

-Created config.py to centralize all simulation parameters, costs, and reward shaping values (R_TASK_COMPLETE, R_TASK_PROGRESS, C_SEND, etc.) across agent.py, policy.py, learning_curve.py, and score_tasks.py, preventing silent metric drift between training and scoring.

-Disabled orchestrator task escalations (the 8.0s "extra" ping and 3.0s "broadcast" fallbacks). Previously, agents learned to "free ride" by choosing "reply" instead of "collab" to save communication costs, letting the orchestrator bail them out. Removing escalations forces agents to actively recruit peers via peer-to-peer invites to meet task quotas.

-Fixed premature convergence / policy collapse where sent messages dropped to zero:
  * Increased R_INVITE_SUCCESS (1.0 -> 2.5) to ensure successful peer recruitment significantly outweighs send and step penalties.
  * Increased LinUCB exploration parameter alpha (1.5 -> 2.5) to maintain healthy exploration of the "collab" arm.
  * Verified over a 30-run sequence: communication stabilized at 45-70 sent messages per run, sustaining a consistent 50%-83% task completion rate.

-Fixed a display bug in learning_curve.py that was printing duplicate rows per run.

9/17/26
-Decoupled agent execution from direct environment state access to establish a fully decentralized communication protocol:
  * Completely removed TaskManager references and direct method calls (contribute(), record_invite()) from Agent.
  * Migrated task contributions and invite tracking to explicit asynchronous bus messages (task_contribute, task_invite_record) routed over InMemoryBus.
  * Added a dedicated system bus listener in orchestrator.py to process inbound requests, evaluate deadlines/quotas, and dispatch acknowledgments (task_contrib_ack, invite_credit_notice, task_complete_notice) back to agents.
  * Updated bus.py to support a centralized system queue interface.

-Evaluated decentralized learning dynamics across an extended 30-run sequence:
  * Confirmed strong learning progression, rising from an average score of 0.61 (first half) to 23.74 (second half), peaking at 100% completion and 63.36 net score.
  * Observed emergent communication redundancy: under asynchronous propagation delays, agents compensated for latency by scaling message frequency (~140-200 sent per run) to guarantee quota fulfillment and avoid task failure penalties.
